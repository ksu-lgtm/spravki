# Учёт заявок на справки колледжа

Учебная практика УП.09.01, вариант 18. Автор: Кочеткова К.А., группа 4ИСИП-1023.

## Версии
- PHP: 8.0
- MySQL: 8.0
- Веб-сервер: Apache 2.4
- phpMyAdmin: 5.2.0

## Запуск
1. Скопировать папку проекта в domains OpenServer.
2. Скопировать config.example.php в config.php и указать параметры БД.
3. Выполнить database/schema.sql, затем database/seed.sql.
4. Запустить OpenServer и открыть http://spravki/
